# thought-searcher (생각 검색기) 🧠

Claude, ChatGPT, Codex 채팅 기록을 내 PC에 영구 보관하고, 내 노트와 업무 일지까지 같이 흐릿한 기억(단어 몇 개)만으로 찾는 트레이 도구입니다. 검색어를 비우면 최근에 손댄 일 목록([열린 일 큐](#열린-일-큐))이 보입니다.
"정리"하지 않고 "다 저장하고 검색"합니다. 수집, 변환, 검색 모두 로컬에서 하고 AI 토큰을 쓰지 않습니다. 큐에서 F2(요약)를 누를 때만 이 PC의 Claude Code 또는 Codex CLI를 실행합니다.

- claude.ai 데이터 내보내기 zip이 다운로드 폴더에 들어오면 자동으로 md로 바꾸고 색인합니다.
- Claude Code 세션(`%USERPROFILE%\.claude\projects`)을 30분마다 md로 바꾸고, 원본 jsonl도 따로 복사해 둡니다(30일 자동 삭제 대비).
  md에는 사람 입력과 Claude 답변 글만 담고, 도구 호출(Bash, Read 등)과 그 결과는 뺍니다.
- Codex 대화(`%USERPROFILE%\.codex`)도 같은 때 같이 모읍니다. Codex DB를 읽기만 하고, 사람 입력과 답변 글만 담습니다.
  Claude Code 세션을 Codex로 옮겨 온 대화는 같은 세션의 Claude Code md가 이미 있으면 건너뛰고, 원본이 지워져 Codex에만 남은 것만 들어옵니다.
- 가져오는 동안 트레이 아이콘에 ⏳가 붙고, 아이콘에 마우스를 올리면 진행 상황(`Claude Code 대화 가져오는 중 (3/14)`)이 보입니다. `지금 가져오기`를 누르면 끝났을 때 `가져오기 완료: 새 대화 N개, 바뀐 대화 M개` 알림이 뜹니다.
- `Ctrl+Alt+H`로 검색 창을 띄웁니다.
- 마지막 가져오기 후 7일이 지나면 내보내기를 받으라고 알려 드립니다(claude.ai를 켰을 때만, 설정에서 끌 수 있음).
- 쓰지 않는 서비스는 설정에서 꺼 두면 수집, 알림, 메뉴가 모두 빠집니다.

## 설치

Python 3.10 이상(python.org 배포판 권장, `sqlite3`에 FTS5가 있어야 함)이 필요합니다.

```bash
cd small-win-tools/thought-searcher
pip install -r requirements.txt
```

> `pip install`을 깜빡하고 바로 실행해도 괜찮습니다. PySide6가 없으면 처음 실행할 때 설치할지 물어보고, **예**를 누르면 새 콘솔 창에서 받습니다(약 80MB, 처음 한 번만).

## 첫 실행

```bash
pythonw thought_searcher.pyw
```

1. 트레이에 🧠 아이콘이 생기고, 처음 한 번만 **시작 안내** 창이 뜹니다(`config.json`이 없을 때만).
   1. 쓰는 서비스(claude.ai, ChatGPT, Claude Code, Codex)를 고릅니다. 끈 서비스는 수집도 알림도 하지 않습니다.
   2. 대화 보관 폴더: 기본 위치 `%LOCALAPPDATA%\thought-searcher\archive`를 그대로 쓰거나 바꿉니다.
   3. F2 요약 AI: Claude, GPT(Codex), 끄기 중 하나. 가장 싼 모델(haiku, gpt-6-luna)로 정해 둡니다.
   4. 노트 폴더(선택)와 claude.ai, ChatGPT 수집 스크립트 설치 안내.

   `마치기`를 누르면 수집을 시작합니다. `건너뛰기`(또는 창 닫기)를 누르면 모든 서비스를 켠 기본값으로 동작합니다. 다음 실행부터는 뜨지 않습니다.
   설정은 언제든 트레이 메뉴 `설정...`이나 검색 창 오른쪽 아래 톱니바퀴 아이콘에서 바꿉니다.
2. claude.ai 대화는 트레이 메뉴 `claude.ai 내보내기 받으러 가기`로 내보내기 페이지를 열어 zip을 받으면 됩니다(메일로 링크가 옵니다). 다운로드 폴더에 들어오면 자동으로 가져옵니다.
   내보내기는 `conversations-000.zip`, `projects-000.zip`, `memories-000.zip` 등 여러 개로 나뉘어 오는데, 필요한 것만 알아서 읽고 나머지는 무시합니다.
   처리한 zip은 지우거나 옮기지 않습니다. 같은 zip을 다시 넣어도 중복되지 않습니다.
   `memories-000.zip`이 안 받아지면 claude.ai 메모리 화면에서 받은 `claude-memory-YYYY-MM-DD.zip`(md 묶음)을 다운로드 폴더에 두세요. 같은 메모리 문서로 들어가고, 둘 중 더 새것이 남습니다.
3. ChatGPT 내보내기 zip(`<긴 해시>-<날짜>-<해시>.zip`)도 다운로드 폴더에 두면 자동으로 가져옵니다. 파일 이름이 아니라 안의 `conversations.json` 구조로 알아봅니다. 생각 과정, 도구 호출, 첨부 원본은 담지 않습니다.

### 시작 프로그램 등록

`Win+R` → `shell:startup` → 열린 폴더에 바로 가기를 만듭니다.

- 대상: `pythonw.exe "D:\...\small-win-tools\thought-searcher\thought_searcher.pyw"`
- 시작 위치: `D:\...\small-win-tools\thought-searcher`

## 검색 문법

검색칸 아래 칩으로 출처(AI, 프로젝트, 메모리, Code, GPT, Codex, 노트, 일지), 기간(1주, 1달, 3달, 올해), 프로젝트, `내 질문`을 고를 수 있습니다. 칩은 아래 문법(`src:`, `after:`, `proj:`, `by:me`)을 대신 붙여 주는 것이라 직접 쳐도 같습니다(손으로 친 조각은 해당 칩이 켜진 것으로만 보입니다). 칩이 하나라도 켜지면 첫째 줄 끝에 `모두 지우기`가 보입니다. 창을 다시 열면 칩은 모두 꺼집니다.

단어를 친 검색에서는 기간 칩과 `after:`, `before:`가 맞은 메시지의 시각을 봅니다. 맞은 메시지 중 하나라도 기간 안이면 남고, 미리보기와 `←` `→`도 기간 안의 메시지만 돕니다. 1년 전 대화에 어제 다른 말을 이어 붙여도 1주 칩에 걸리지 않습니다.

칩 둘째 줄 오른쪽 끝의 `최신 | 정확도` 단추(또는 `Ctrl+R`)로 정렬을 바꿉니다. `최신`은 맞은 메시지가 가장 늦은 대화부터(대화 안에서도 늦은 메시지부터), `정확도`는 아래 순위 순서입니다. 기본값은 `설정 > 일반 > 검색 창 > 기본 정렬`이고, 창에서 바꾼 정렬은 그 검색에만 쓰이며 창을 다시 열면 기본값으로 돌아갑니다.

단어 없이 칩만 고르면 [열린 일 큐](#열린-일-큐)를 그 조건으로 거릅니다. 기간 칩을 고르면 큐 기간도 그만큼 넓어집니다. 메모리, 프로젝트 문서처럼 큐에 오르지 않는 출처라 거른 큐가 비면, 그 조건의 최근 대화 목록이 나옵니다.

| 입력 | 뜻 |
|---|---|
| `로그 배포` | 두 단어가 **대화 안 어디에든** 있으면 찾음 (한 메시지에 같이 있을 필요 없음) |
| `로그배포` | 한글은 띄어쓰기를 무시합니다. `로그 배포`(구문)와 같은 것을 찾습니다 |
| `log` | 영어는 앞부분만 맞아도 찾음 (`logpick`, `logcut`) |
| `"nginx 설정"` | 구문: 붙어서 나와야 함 |
| `-롤백` | 제외: 이 단어가 있는 대화는 뺌 |
| `src:ai` `src:code` `src:codex` `src:project` `src:memory` `src:gpt` `src:note` | 출처 필터 (`src:노트`도 됨) |
| `proj:small` | 프로젝트 이름 일부 |
| `after:2026-10` `before:2026-11-05` | 날짜 범위 (단어가 있으면 맞은 메시지의 시각 기준) |
| `by:me` (`by:나`) | 내 질문만: 모든 검색 단어가 그 대화의 **내가 쓴 메시지**에 있어야 합니다(단어마다 다른 메시지여도 됨). 미리보기, `←` `→`, 채팅 시각도 내 메시지만 봅니다. 노트, 일지, 프로젝트 문서, 메모리는 내 메시지가 없어 빠집니다. 칩 `내 질문`과 같습니다 |
| `배` (1글자) | 제목에서만 찾음 |
| (빈 입력) | 최근 대화 목록 |

**결과가 0건일 때**만 두 가지를 더 합니다.

- **한영 자판 보정**: 검색 단어(문법 조각과 따옴표 구문 밖의 낱말)를 하나씩 봅니다. 영문 자판으로 친 한글(`ㅜㅎㅑㅜㅌ`, `ㅜ햐ㅜㅌ`)은 영문(`nginx`)으로, 한글 자판 오타처럼 보이는 영문 소문자(`qovh`)는 한글(`배포`)로 바꿔 다시 찾습니다. 결과가 있으면 보여 주고 상태 자리에 `nginx로 찾았습니다`를 적습니다. 검색칸 글자는 바꾸지 않습니다. 완성된 한글 낱말은 영문으로 바꾸지 않습니다.
- **0건 안내**: 보정까지 해도 0건이고 조건(출처 칩, 기간 칩, 프로젝트 칩, `내 질문`, 손으로 친 `src:` `after:` `before:` `proj:` `by:` `-제외어`)이 걸려 있으면, 조건을 하나씩 빼 보고 가장 많이 나오는 조건을 목록 자리에 한 줄로 알려 줍니다(`출처를 제외하면 12건입니다`). 하나만 빼서는 모두 0건이면 `모든 조건을 제외하면 N건입니다`. 줄을 누르거나 `Enter`를 치면 그 조건의 칩을 끄고 검색칸에 친 조각을 지운 뒤 다시 찾습니다. 조건이 없거나 다 빼도 0건이면 그냥 `결과 없음`입니다.

순위는 BM25 관련도에 제목 일치, 한 메시지 안 동시 등장, 최근 대화 가산을 더해 정합니다. 가중치는 `설정 > 고급 > 순위 가중치`에서 바꿀 수 있습니다.

### 검색 창 화면

- 맨 위에 큰 검색칸이 있고, 오른쪽에 결과 수(또는 상태)가 보입니다. 결과는 한 줄씩(출처 배지, 제목, 프로젝트, 날짜 MM-DD)이고 고른 줄은 바탕색과 왼쪽 강조색 막대로 표시됩니다.
- 창 폭이 760px 이상이면 왼쪽 목록 | 오른쪽 미리보기 칸입니다. 미리보기에는 맞은 메시지와 그 앞뒤 메시지 하나씩, 맞은 낱말 강조, `맞은 메시지 i / n`이 보입니다. 나누기 막대를 끌어 목록 폭을 바꿀 수 있습니다.
- 760px보다 좁으면 목록만 보이고, 고른 줄만 두 번째 줄에 맞은 메시지 미리보기와 `Alt ← i/n →`를 보여 줍니다.
- 빈 검색어(열린 일 큐)도 같은 줄 모양입니다. 미리보기 칸에 보이는 것은 아래 [열린 일 큐](#열린-일-큐)에 있습니다.
- 아래 막대에 설정(톱니바퀴), 앱 이름, 키 안내가 있습니다.
- 창 테두리(6px)나 오른쪽 아래 모서리 표시를 끌면 크기가 바뀝니다. 크기와 나누기 위치는 이 PC의 `%LOCALAPPDATA%\thought-searcher\ui_state.json`에 저장되며 설정 창에는 항목이 없습니다. Windows 11에서는 창 모서리가 둥글게 보입니다.

### 검색 창 키

| 키 | 동작 |
|---|---|
| `↑` `↓` | 결과 이동 |
| `Alt+←` `Alt+→` | 같은 대화의 다른 맞은 메시지로 미리보기 전환 (그냥 `←` `→`는 검색어 커서 이동) |
| `Enter` | md를 맞은 메시지 줄에서 열기 (기본 VS Code, 실패하면 기본 연결 프로그램) |
| `Ctrl+Enter` | 미리보기 중인 메시지 본문 복사 |
| `Shift+Enter` | 대화 전체 md 복사 |
| `Ctrl+R` | 정렬 `정확도` <-> `최신` (그 검색에만) |
| `Esc` | 닫기 |

## 열린 일 큐

검색어를 비우면 최근에 흔적이 있는 일 목록이 보입니다. 할 일을 직접 적지 않아도 이미 모으는 기록에서 저절로 만들어집니다. 일 하나는 대화(또는 노트) 하나입니다.

- **목록**: 최근 14일(`설정 > 일반 > 열린 일 기간`) 안에 흔적이 있는 일을 마지막 흔적이 늦은 순으로 보여 줍니다. 위 5개(`기본 노출 개수`)만 펼쳐 두고 나머지는 `나머지 N개` 줄에 접혀 있습니다. 흔적이 끊긴 일은 목록에서만 빠지고 검색으로는 계속 찾을 수 있습니다.
- **올라오는 출처**: `설정 > 일반 > 큐에 올릴 출처`에서 고릅니다(기본 claude.ai, Claude Code, 노트. ChatGPT, Codex도 고를 수 있음). claude.ai 프로젝트 문서, 메모리, `imported\` 대화는 올리지 않습니다. `큐에서 뺄 노트 폴더`에 넣은 폴더(템플릿 등)도 빠집니다.
- **업무 일지**: `업무 일지 폴더`를 정하면 일지(`YYYY/MM/YYYY-MM-DD.md`)의 `## 업무` 항목도 올라옵니다. 항목에 `[session:: <세션 id>]`가 있으면 그 대화에 붙고, 없으면 항목 하나가 일 하나가 됩니다. 일지는 읽기만 합니다.
- **닫기**: `F4`는 완료, `Shift+F4`는 버림입니다. 일지에서 항목을 `[x]`(완료)나 `[-]`(버림)로 바꿔도 닫힙니다. 그 항목 아래에 `[ ]` 하위 항목이 남아 있으면 열린 채로 둡니다. 닫은 뒤 새 흔적이 생기면 저절로 다시 열립니다. 목록 맨 아래 `닫은 일 보기`에서 닫은 일을 고르고 `F4`를 누르면 다시 엽니다.
- **미리보기**(창 폭 760px 이상): 위쪽에 최근 대화 5턴이 `나` / `AI`로 한 줄씩 보입니다. 일지 항목은 최근 일지 5개, 노트는 끝부분 5줄입니다. 그 아래에 저장된 요약이 있습니다. 좁은 창에서는 목록 아래에 요약만 보입니다.
- **F2 요약**: 고른 일 하나를 `설정 > 요약 AI`에서 고른 CLI로 "어디까지 했나 / 남은 일 / 다음 한 걸음" 세 덩어리로 정리합니다. 누를 때만 실행하고, 결과는 저장해 두었다가 다시 고르면 바로 보여 줍니다. 요약한 뒤 새 흔적이 생기면 `요약 이후 새 흔적 있음`이 붙습니다. 요약 칸은 끌어서 고른 뒤 `Ctrl+C`나 오른쪽 클릭으로 복사합니다.

| 키 | 동작 |
|---|---|
| `↑` `↓` | 일 이동 (저장된 요약만 보여 주고 AI는 부르지 않음) |
| `Enter` | 열기: 대화는 마지막 메시지 줄, 노트와 일지 항목은 그 파일 그 줄 |
| `F2` | 요약 (요약 AI를 끄면 숨겨짐) |
| `F4` / `Shift+F4` | 완료 / 버림 (닫은 일에서는 `F4`가 다시 열기) |
| `Shift+Enter` | 대화 전체 md 복사 |
| 오른쪽 클릭 | 같은 동작 메뉴 |

## 설정 창

`config.json`을 몰라도 바꿀 수 있는 설정은 모두 여기서 바꿉니다. 창을 만드는 몇 초 동안은 `여는 중` 상자가 뜨고 마우스 커서가 모래시계로 바뀝니다. 맨 위 `설정 찾기` 칸(`Ctrl+F`)에 글자를 넣으면 모든 탭에서 이름, 설명, 툴팁(이름 옆 ⓘ)이 맞는 줄만 남기고, 왼쪽 메뉴에 탭별 맞은 수가 붙습니다. 왼쪽 메뉴에서 일반, 수집, 요약 AI, 고급 중 하나를 고릅니다. 아래 막대에는 바뀐 설정 수가 보이고 `Ctrl+S`로 저장, `Esc`로 취소합니다. `저장`을 누르면 칸을 검사한 뒤 재시작 없이 바로 적용됩니다. 잘못된 칸은 그 메뉴로 가서 칸 아래 빨간 줄로 알려 줍니다.

| 메뉴 | 항목 |
|---|---|
| 일반 | 검색 창 단축키(칸을 누르고 새 조합을 누름, 저장할 때 등록해 보고 실패하면 옛 키 유지), 기본 정렬(최신/정확도, 기본 최신), 모양(모드: 라이트/다크/시스템, 강조색: 잉크 블루/딥 틸/세이지 그린/러스트), 대화 보관 폴더, 노트 폴더, 업무 일지 폴더, 열린 일 기간과 개수, 큐에 올릴 출처, 큐에서 뺄 노트 폴더 |
| 수집 | 쓰는 서비스, 다운로드(감시) 폴더, 자동 수집 파일 폴더, Claude Code/Codex 폴더, 수집 주기, 내보내기 알림(끄기 가능), 수집 멈춤 알림, 수집 스크립트 설치 안내와 `스크립트 복사` |
| 요약 AI | Claude / GPT (Codex) / 끄기, 모델, GPT 추론 정도, CLI 상태(버전과 로그인만 확인, 토큰 안 씀), CLI 경로 |
| 고급 | md 여는 명령, 검색 결과 개수, 순위 가중치, 추가 가림 정규식, 요약 재료 크기와 제한 시간, 내보내기 페이지 주소, config.json/데이터 폴더 열기 |

- 모드와 강조색은 고르는 즉시 설정 창에 먼저 보여 주고, 저장하면 검색 창과 트레이 메뉴에도 적용됩니다. `시스템`은 Windows 앱 모드를 따라가며, Windows에서 바꾸면 앱이 켜진 채로 바로 바뀝니다.
- 창에 없는 키(손으로 넣은 키)는 저장해도 그대로 남습니다. 바꾼 칸만 파일에 씁니다.
- 창을 연 뒤 `config.json`을 메모장 등으로 고쳤다면 저장할 때 `덮어쓰기 / 다시 읽기`를 묻습니다.
- 쓰는 서비스를 끄면 그 서비스의 수집, zip 가져오기, 알림, 메뉴가 멈추거나 숨겨집니다. 이미 보관된 md는 계속 검색됩니다. 끈 동안 들어온 zip은 이력에 남기지 않으므로 나중에 켜면 가져옵니다.

### 요약 AI 고르기 (F2)

앱은 CLI를 설치하거나 로그인하지 않습니다. 상태만 보여 줍니다.

| 고르기 | 필요한 것 | 기본 모델 |
|---|---|---|
| Claude | Claude Code CLI(`claude`)가 PATH에 있고 `claude`로 로그인 | `haiku` |
| GPT (Codex) | Codex CLI. PATH의 `codex`, 없으면 Codex 데스크톱 앱이 넣은 `%LOCALAPPDATA%\OpenAI\Codex\bin\*\codex.exe`를 찾음. `codex login`으로 ChatGPT 로그인 | `gpt-6-luna` |
| 끄기 | 없음 | |

- GPT 모델 목록은 이 PC의 Codex가 받아 둔 `%USERPROFILE%\.codex\models_cache.json`에서 읽습니다.
- Codex 요약은 `codex exec --ephemeral -s read-only --ignore-user-config ...`로 실행해 세션 기록을 남기지 않습니다(Codex 수집에 요약 대화가 섞이지 않음).
- 요약 줄 끝에 만든 모델이 `claude:haiku`, `codex:gpt-6-luna`처럼 보입니다.

### ChatGPT만 쓰는 경우

시작 안내 1단계에서 ChatGPT만 체크하면 claude.ai 내보내기 알림과 메뉴가 사라지고, 큐에는 ChatGPT 대화와 노트가 올라오며, 요약 AI는 GPT로 정해집니다.
ChatGPT 대화는 내보내기 zip을 다운로드 폴더에 두거나, 설정 > 수집 탭 안내대로 `chatgpt-sync.user.js`를 설치해 모읍니다. 회사 크롬 정책으로 확장 설치가 막혀 있으면 zip 내보내기로 가져오면 됩니다.

## claude.ai, ChatGPT 자동 수집 (Tampermonkey)
zip 내보내기를 기다리지 않고, claude.ai 탭이 열려 있는 동안 30분마다 바뀐 대화만 받아 둡니다. 주로 계속 켜 두는 PC용입니다.
앱은 받은 파일을 2초마다 확인해 바뀐 것만 보관 폴더에 넣습니다(파일은 지우지 않음. 아래 '개인 대화 빼기'로 뺀 대화만 지움). 프로젝트 문서와 메모리는 여전히 zip으로만 들어오므로 주간 내보내기 알림은 그대로 뜹니다.

1. Tampermonkey 확장을 설치합니다.
2. Tampermonkey 설정
   - 일반 > 설정 모드: `고급`
   - 다운로드 BETA > 다운로드 모드: `브라우저 API`, 허용 확장자(화이트리스트)에 `.json` 추가
   - 처음 저장할 때 크롬이 다운로드 권한을 물으면 허용합니다.
3. 크롬 설정 > 다운로드 > "다운로드 전에 각 파일의 저장 위치 확인"을 끕니다.
4. 크롬 설정 > 성능 > 메모리 절약 모드를 쓰면 `claude.ai`를 "항상 활성 상태로 유지할 사이트"에 넣습니다.
5. Tampermonkey 대시보드 > 새 스크립트에 `userscript/claude-sync.user.js` 내용을 붙여 넣고 저장합니다. ChatGPT도 받으려면 `userscript/chatgpt-sync.user.js`를 같은 방법으로 하나 더 넣습니다. 설정 > 수집 탭의 `스크립트 복사` 버튼으로 내용을 바로 복사할 수 있습니다.
6. claude.ai를 열면 15초 뒤 첫 수집이 돕니다. 확장 아이콘의 스크립트 메뉴에서 `지금 수집`, `상태 보기`를 쓸 수 있습니다.

저장 위치는 둘 다 다운로드 폴더의 `claude-sync\`입니다. 대화 하나가 파일 하나(`claude-ai_<uuid>.json`, `chatgpt_<id>.json`)이고, 돌 때마다 `_status.json`(claude.ai), `_status_chatgpt.json`(ChatGPT)이 갱신됩니다. ChatGPT 대화는 프로젝트 이름 없이 들어옵니다.
첫 실행에서는 전체 대화를 50개씩 나눠 받습니다(3분 간격으로 이어 받음).
파일이 `claude-sync\` 대신 다운로드 폴더 바로 아래 `claude-ai_... (1).json`처럼 쌓이면 2번 설정(브라우저 API 모드)을 다시 확인하세요. 앱도 한 번 알려 줍니다.
수집이 3시간 넘게 멈추면(탭을 닫았거나 로그아웃) 하루 한 번 트레이 알림이 뜹니다. 상태 보기에 마지막 성공 시각이 나옵니다.
설정: `capture_dir`(비면 `<watch_dir>\claude-sync`), `capture_stale_hours`(기본 3). 수집을 한 번도 하지 않은 PC에서는 아무 알림도 뜨지 않습니다.

### 개인 대화 빼기 (claude.ai)

검색에 넣고 싶지 않은 대화나 프로젝트는 claude.ai에서 그 화면을 연 채로 확장 아이콘의 스크립트 메뉴에서 뺍니다.

| 메뉴 | 동작 |
|---|---|
| `이 대화 수집에서 빼기` | 지금 연 대화를 앞으로 받지 않습니다 |
| `이 프로젝트 수집에서 빼기` | 프로젝트 화면이나 프로젝트 안의 대화에서 누릅니다. 그 프로젝트의 대화, 프로젝트 문서, 프로젝트 메모리를 받지 않습니다. 프로젝트 대화를 찾느라 곧 전체 대화 목록을 한 번 훑습니다 |
| `수집에서 뺀 목록 (되돌리기)` | 뺀 목록을 보고 번호를 넣어 되돌립니다. 되돌린 대화는 곧 다시 받고, 프로젝트 문서는 다음 zip을 가져올 때 돌아옵니다 |

- 목록은 브라우저(Tampermonkey)에 저장되고, 스크립트가 `_status.json`에 같이 적어 앱에 알립니다.
- 앱은 목록을 받으면 그 대화의 **이미 모은 md, 다운로드 폴더의 수집 파일, 원본 사본, F2 요약을 지우고 검색 색인에서도 뺍니다.** 내보내기 zip을 가져올 때도 뺍니다.
- 앱은 대화 ID로 찾아 지우므로 제목이 바뀐 대화도 정확히 지웁니다. 빼기 전에 받은 zip 파일 자체는 다운로드 폴더에 그대로 남으니 필요하면 직접 지우면 됩니다.
- ChatGPT, Claude Code, Codex에는 아직 없습니다.

## 보관 폴더 주의 ⚠

- **회사 PC 보관본을 개인 클라우드(OneDrive 개인, Google Drive 등)에 두지 마세요.** PC마다 보관 폴더를 따로 정하고, 서로 공유하거나 합치지 않습니다.
- md는 도구가 항상 다시 만들어 덮어씁니다. 직접 고친 내용은 보존되지 않습니다.
- 원본에서 사라진 대화도 md는 지우지 않고 `source_status: missing`으로 표시만 합니다. md를 지우는 것은 직접 수집에서 뺀 claude.ai 대화뿐입니다.
- md에 쓰기 전에 알려진 형식의 비밀 값(API 키, 토큰, 개인 키 등)을 `***가림:<종류>***`로 바꿉니다. 원본 zip과 jsonl 복사본은 그대로입니다. 회사 전용 형식은 `extra_redact_patterns`에 정규식으로 추가하면 됩니다.
- 보관 폴더가 없어지면(드라이브 분리 등) 수집을 멈춥니다. 엉뚱한 곳에 쌓이지 않도록 폴더를 새로 만들지 않습니다.

## 내 노트 md 넣기 (노트 폴더)

Obsidian 일지, 메모처럼 직접 쓴 md는 `설정 > 일반 > 노트 폴더`에서 `추가...`로 폴더를 고르면 형식 변환 없이 그대로 검색됩니다.

- 파일은 **읽기만** 합니다. 복사하거나 고치지 않고, 보관 폴더에도 쓰지 않습니다.
- 하위 폴더까지 모두 읽고, 점으로 시작하는 폴더(`.obsidian`, `.git` 등)는 건너뜁니다.
- 검색 결과에 `노트` 배지로 나오고, `src:note`로 노트만 찾을 수 있습니다. `proj:`에는 `폴더 이름/하위 폴더`가 들어갑니다(예: `proj:MyVault/2026`).
- 제목은 파일 이름(frontmatter `title`이 있으면 그것)입니다.
- 날짜는 frontmatter `date`, 파일 이름의 `YYYY-MM-DD`/`YYYYMMDD`, 파일 수정 시각 순으로 정합니다. 일지는 고친 날이 아니라 일지 날짜로 정렬됩니다.
- `#` 제목마다 구역으로 나눠 색인하고, 구역 제목도 검색됩니다. Enter를 누르면 원본 파일이 맞은 줄에서 열립니다.
- 바뀐 노트는 30분마다(`지금 가져오기`를 누르면 바로) 반영됩니다.

## 다른 곳의 대화 md 넣기

다른 도구에서 md로 내보낸 대화는 보관 폴더의 `imported\`에 정해진 형식으로 넣으면 같이 검색됩니다. 형식과 방법은 [MD_IMPORT.md](MD_IMPORT.md)에 있습니다.
