# 다른 곳의 대화 md 넣기

Codex 기록, 다른 도구로 저장한 대화 같은 md를 생각 검색기에서 함께 검색하는 방법입니다.

## 1. 넣는 곳

```
%LOCALAPPDATA%\thought-searcher\archive\imported\
```

- 트레이 메뉴 `대화 보관 폴더 열기`로 연 폴더 안에 `imported` 폴더를 만들고 넣으면 됩니다. 하위 폴더는 자유롭게 만들어도 됩니다.
- 넣은 뒤 앱을 다시 켜거나 트레이 메뉴 `지금 가져오기`를 누르면 검색에 잡힙니다.
- 도구는 이 폴더의 파일을 **읽기만 하고 고치거나 지우지 않습니다.**
- 보관 폴더를 바꿨다면 그 폴더 안의 `imported\`에 넣으세요.

## 2. 파일 형식

아래 형식을 지킨 md만 검색에 들어갑니다. 형식이 맞지 않는 md는 조용히 무시합니다.

```markdown
---
id: codex-md:2026-11-01-deploy-script
source: codex-md
title: 배포 스크립트 정리
project: demo-proj
created: 2026-11-01T10:00:00+09:00
updated: 2026-11-01T10:30:00+09:00
format_version: 1
---

# 배포 스크립트 정리

<!-- bs:msg 1 user 2026-11-01T10:00:00+09:00 -->
## 🧑 사용자

젠킨스 파이프라인 고쳐 줘

<!-- bs:msg 2 assistant 2026-11-01T10:01:00+09:00 -->
## 🤖 Codex

stage 순서를 바꿨습니다.
```

### 머리말 (맨 위 `---` 사이)

| 항목 | 필수 | 설명 |
|---|---|---|
| `id` | 예 | `<출처>:<고유 이름>`. **파일마다 달라야 합니다.** 같은 id가 두 개면 `updated`가 최신인 것 하나만 검색됩니다 |
| `source` | 예 | 출처 이름. `codex-md`, `my-notes`처럼 자유롭게. `claude-ai`, `claude-code`는 쓰지 마세요 |
| `format_version` | 예 | `1` |
| `title` | 권장 | 검색 결과 첫 줄에 보이는 제목. 제목 일치는 순위가 높아요 |
| `created`, `updated` | 권장 | `2026-11-01T10:00:00+09:00` 형식. 정렬, 날짜 필터(`after:`, `before:`), 최근 가산에 씁니다 |
| `project` | 선택 | `proj:` 필터와 결과 표시에 씁니다 |

### 메시지

- 메시지마다 `<!-- bs:msg <번호> <user 또는 assistant> <시각> -->` 한 줄을 먼저 쓰고, 바로 다음 줄에 `## 제목`을 씁니다. 제목 글은 자유입니다.
- 번호는 1부터 차례로 씁니다.
- 본문은 그다음 줄부터 다음 표식 전까지입니다. 본문 안에 `##` 제목이 있어도 괜찮습니다.
- 표식이 하나도 없으면 제목만 검색됩니다. 대화가 아닌 메모라면 표식 하나(`1 user`) 아래에 본문 전체를 넣으세요.

## 3. 변환을 AI에게 맡길 때

가지고 있는 md를 이 형식으로 바꿀 때는 아래 문장을 그대로 주면 됩니다.

> 이 폴더의 대화 md를 thought-searcher `MD_IMPORT.md`의 "파일 형식"대로 바꿔 새 폴더에 저장해 줘. 파일마다 머리말(id는 `codex-md:<원래 파일 이름>`, source는 `codex-md`, title, created, updated, format_version: 1)을 넣고, 사람 입력과 AI 답변을 `<!-- bs:msg 번호 user|assistant 시각 -->` + `## 제목` 줄로 나눠 줘. 시각을 모르면 파일 수정 시각을 써. 원본 파일은 건드리지 마.

## 4. 주의

- 비밀 값 가림(API 키 등)은 도구가 직접 만드는 md에만 적용됩니다. **직접 넣는 md는 넣기 전에 직접 확인하세요.**
- 회사 대화는 회사 PC에만 넣으세요.
- 검색 결과에는 `MD` 표시로 나옵니다.
