# emoji-searcher 명세

> 저장소: `GCxEnding/small-win-tools` (공개)
> 위치: `small-win-tools/emoji-searcher/`

## 1. 개요
- 목적: 노트 제목 맨 앞에 붙일 이모지를 빠르게 찾아 입력한다. Windows 기본 이모지 패널(Win+.)은 검색 키워드가 적고 한국어 검색이 약해서, AI로 미리 만든 풍부한 한/영 태그로 검색하는 작은 실행기를 만든다.
- 보조 목적: 예전에 자주 쓴 이모지가 위에 올라오게 해서 "전에 뭘 썼더라"를 대략 떠올릴 수 있게 한다.
- 사용자: CG 본인. 회사 PC와 집 PC(둘 다 Windows)에서 사용. IT 숙련도 높음.

## 2. 범위
### 포함
- 트레이 상주 + 전역 단축키(Win+.)로 검색 창 호출
- 한국어/영어 태그 검색, 초성 검색, 한영 자판 혼동 보정
- 선택한 이모지를 원래 창에 자동 붙여넣기
- 앱에서 고른 이모지의 사용 횟수/최근 사용 기록 저장 및 정렬 반영
- 개인 태그 파일(`user_tags.json`) 직접 편집으로 태그 추가
- 태그 데이터 생성용 빌드 스크립트 (개발 시에만 실행)
- Win+. 기본 동작을 끄고 되돌리는 .reg 파일 2개

### 제외 (Out of scope)
- 실행 중 AI/API 호출 (태그는 개발 시 한 번 생성해 동봉)
- 앱 안의 태그 편집 화면
- Obsidian 보관함 등 노트 제목 스캔
- 회사/집 PC 간 개인 데이터 동기화
- 격자형 화면, 피부색 변형 선택 UI
- 설치 프로그램(exe 패키징). Git clone + pip 설치로 충분

## 3. 기능 요구사항
1. **상주와 호출**
   - `emoji_searcher.pyw` 실행 시 창 없이 트레이 아이콘으로 상주한다.
   - Win+.을 누르면 검색 창이 마우스 커서 위치에 우클릭 메뉴처럼 뜨고(화면 밖으로 나가면 위/왼쪽으로 뒤집음, `position: "center"`면 모니터 중앙) 입력란에 포커스가 간다.
   - 이미 떠 있는 상태에서 다시 누르면 창을 숨긴다(토글).
   - 트레이 메뉴: `열기`, `데이터 폴더 열기`, `개인 태그 다시 읽기`, `종료`.
   - 중복 실행 방지: 두 번째 실행은 즉시 종료한다(이름 있는 뮤텍스).
2. **검색**
   - 입력할 때마다 즉시 검색한다. 한글 조합 중(예: "불" 입력 중 "ㅂ", "부")에도 결과가 갱신되어야 한다.
   - 매칭 대상: 이모지 이름(ko/en), CLDR 키워드(ko/en), AI 태그(ko/en), 개인 태그.
   - 초성 검색: 입력이 한글 자음(ㄱ~ㅎ)으로만 이루어지면 태그의 초성열과 매칭한다. 예: `ㅂㅍ` → "배포" → 🚀
   - 한영 자판 혼동 보정: 입력이 영문 자판 문자로만 이루어지면 원문 그대로도 검색하고, 두벌식 기준 한글로 변환한 결과로도 검색해 합친다. 예: `qnf` → "불" → 🔥, `qovh` → "배포" → 🚀
   - 대소문자, 앞뒤 공백 무시. 유니코드 NFC 정규화.
   - 여러 단어 입력(공백 구분)은 모든 단어가 매칭되는 이모지만 표시(AND).
3. **정렬**
   - 기본 점수: 정확히 일치 > 앞부분 일치 > 부분 포함. 개인 태그 매칭은 가중치를 더 준다.
   - 보정 점수: 사용 횟수와 최근 사용 시점을 반영한다. 단, 검색어 매칭 품질을 뒤집을 만큼 크지 않게 한다(정확 일치가 항상 부분 포함보다 위).
   - 입력이 비어 있으면 최근 사용 순 목록을 보여 준다(없으면 빈 화면 + 안내 문구).
4. **화면 (목록형)**
   - 한 줄: `이모지 | 이름(ko) | 매칭된 태그 일부`
   - 최대 표시 개수는 설정값(기본 30), 스크롤 가능.
   - 키 조작: ↑/↓ 이동, Enter 선택, Esc 닫기, 창 밖 클릭 시 닫기.
   - 컬러 이모지가 제대로 보여야 한다(Segoe UI Emoji).
5. **선택과 입력**
   - 창을 띄우기 직전의 포그라운드 창을 기억한다.
   - Enter 시 이모지를 클립보드에 넣고(기존 내용은 덮어씀), 창을 숨기고, 기억한 창으로 포커스를 돌린 뒤 Ctrl+V를 보낸다.
   - 사용 기록을 갱신한다.
6. **개인 태그**
   - `%APPDATA%\emoji-searcher\user_tags.json`을 사용자가 직접 편집한다.
   - 앱 시작 시, 그리고 트레이 메뉴 `개인 태그 다시 읽기` 시 다시 읽는다.
   - 파일이 없으면 예시가 들어간 빈 파일을 만들어 둔다.

## 4. 입력과 데이터
### 동봉 데이터 (저장소에 커밋)
- `data/emoji_tags.json`: 빌드 스크립트가 만든 최종 검색 데이터
  ```json
  [
    {
      "emoji": "🚀",
      "name_ko": "로켓",
      "name_en": "rocket",
      "group": "Travel & Places",
      "keywords_ko": ["로켓", "우주"],
      "keywords_en": ["rocket", "space"],
      "tags_ko": ["배포", "출시", "릴리즈", "시작", "발사"],
      "tags_en": ["deploy", "launch", "release", "ship"]
    }
  ]
  ```
- 원천:
  - 이모지 목록: Unicode `emoji-test.txt`의 `fully-qualified` 항목
  - 이름/키워드: Unicode CLDR annotations (ko, en)
  - AI 태그: 개발 세션에서 Claude가 그룹 단위로 생성한 `tags_ko`, `tags_en` (이모지당 대략 5~15개, 실무/노트 제목 용도 연상어 위주)

### 개인 데이터 (PC별, 저장소 밖)
위치: `%APPDATA%\emoji-searcher\`
- `user_tags.json`: `{"🔥": ["긴급", "핫픽스"], "🧪": ["실험실"]}`
- `usage.json`: `{"🚀": {"count": 12, "last_used": "2026-11-04T10:12:00"}}`
- `config.json`:
  ```json
  {
    "hotkey": "win+.",
    "fallback_hotkey": "ctrl+alt+e",
    "max_results": 30,
    "position": "cursor"
  }
  ```

## 5. 엣지 케이스와 처리 규칙
| 상황 | 처리 |
|---|---|
| Win+. 등록 실패 (레지스트리 미적용, 다른 프로그램 선점) | `fallback_hotkey`로 등록하고 트레이 알림으로 어떤 키로 등록됐는지 알린다 |
| 보조 단축키도 실패 | 트레이 알림 후 트레이 메뉴 `열기`로만 사용 가능 |
| 붙여넣기 대상 창이 관리자 권한으로 실행 중 (UIPI로 입력 차단) | 클립보드에는 이미 들어가 있으므로 "클립보드에 복사됨" 트레이 알림 |
| 기억한 창이 그사이 닫힘 | 붙여넣기 생략, 클립보드 복사 + 알림 |
| `user_tags.json` JSON 깨짐 | 개인 태그 없이 동작, 트레이 경고. 파일은 절대 덮어쓰지 않는다 |
| `user_tags.json`에 데이터에 없는 이모지 | 개인 태그만 가진 항목으로 검색 결과에 포함 |
| `usage.json` 깨짐 | `usage.json.bak`으로 이름을 바꿔 보관하고 새로 시작 |
| 개인 데이터 저장 중 강제 종료 | 임시 파일에 쓴 뒤 교체(원자적 저장)해서 깨짐 방지 |
| 검색 결과 없음 | "결과 없음" 한 줄 표시 |
| 영문 입력이 실제 영단어이자 한글 변환도 가능 (예: `rk`) | 두 결과를 합치고 점수로 정렬. 중복 제거 |
| 초성과 일반 한글이 섞인 입력 (예: `배ㅍ`) | 일반 부분 일치로만 처리 (초성 검색은 자음만 있을 때) |
| 다중 모니터 | 마우스 커서가 있는 모니터 안에서 커서 위치 기준으로 표시 |
| 창이 떠 있는 채로 포커스 잃음 | 창 숨김 |

## 6. 제약
- 실행 환경: Windows 10/11, 회사 PC와 집 PC. pip 사용 가능.
- 기술 스택 (가정, 9번 참고):
  - Python 3.10 이상
  - UI/트레이: PySide6 (컬러 이모지 렌더링, 한글 IME 조합 처리, 트레이 지원)
  - 전역 단축키, 포커스 복귀, Ctrl+V 전송: `ctypes`로 Win32 API 직접 호출 (`RegisterHotKey`, `GetForegroundWindow`, `SetForegroundWindow`, `SendInput`)
  - 한글 초성/자판 변환: 직접 구현 (외부 라이브러리 없이 유니코드 계산)
- 이모지 범위: Windows의 Segoe UI Emoji가 표시하는 범위로 제한. 빌드 스크립트에 최대 Emoji 버전 설정값을 두고 기본 15.0으로 한다. 피부색 변형은 제외.
- 성능: 단축키를 누르고 창이 뜨기까지, 그리고 한 글자 입력 후 결과 갱신까지 체감 지연이 없어야 한다(목표 100ms 이하).
- 보안·네트워크: 실행 중 네트워크 접근 없음. 공개 저장소이므로 개인 데이터는 저장소에 넣지 않는다.

## 8. 레지스트리 설정 (Win+. 기본 동작 끄기)
### 원리
- 위치: `HKEY_CURRENT_USER\SOFTWARE\Microsoft\Windows\CurrentVersion\Explorer\Advanced`
- 값: `DisabledHotkeys` (문자열 값, REG_SZ)
- 문자열의 **각 글자가 가상 키 코드(VK)로 해석**되어, 해당 키의 Win 조합이 꺼진다.
- 주의: 글자 `.`(0x2E)는 VK로는 Delete 키라서 **`.`을 넣으면 Win+Delete가 꺼집니다.** 마침표 키의 VK는 `VK_OEM_PERIOD`(0xBE)이고, 이에 해당하는 글자는 `¾`입니다.
- 주의: 이미 Win+V를 끄려고 `V`를 넣어 두셨다면, 새 값으로 덮어쓰면 Win+V가 다시 살아납니다. 그래서 두 글자를 함께 넣습니다.

### 파일
.reg 대신 PowerShell 스크립트로 바꿨다. 현재 값을 읽어서 고치므로 `V` 같은 기존 값이 덮어써지지 않는다.
- `registry/disable-win-period.cmd`: 현재 `DisabledHotkeys` 뒤에 `¾`만 덧붙인다 (예: `V` → `V¾`). 이미 있으면 아무것도 안 함.
- `registry/restore-win-period.cmd`: `¾`만 뺀다 (예: `V¾` → `V`). 비면 값 자체를 삭제.
- 둘 다 변경 직전 `Advanced` 키를 `registry/backup/`에 .reg로 백업하고, 끝에 Explorer 재시작 여부를 묻는다. HKCU만 건드려 관리자 권한 불필요.

### 적용 순서
1. `disable-win-period.cmd` 더블클릭 (현재 값과 변경 후 값이 표시됨)
2. 물어보면 Y로 Explorer 재시작 (또는 나중에 작업 관리자에서 Windows 탐색기 다시 시작 / 로그아웃 후 로그인)
3. Win+.을 눌러 기본 이모지 패널이 안 뜨는지 확인

## 9. 결정 사항과 근거
| 결정 | 이유 | 버린 대안 |
|---|---|---|
| 트레이 상주 + 전역 단축키 | 즉시 호출, 붙여넣기 대상 창을 정확히 기억 | 매번 실행 (뜨는 지연, 대상 창 파악 애매) |
| Win+. 사용 | 익숙한 키. 기본 기능은 레지스트리로 끔 | 별도 조합키만 사용 |
| 자동 붙여넣기, 클립보드 덮어씀 | 가장 빠른 흐름, 구현 단순 | 복사만 / 클립보드 복원 |
| 태그 미리 생성 + 개인 태그 파일 | 실행 시 네트워크·API 키 불필요, 회사 망에서도 동작 | 앱 내 API 호출 |
| 개인 태그는 파일 직접 편집 | 구현 최소화 | 앱 내 편집 화면 |
| 사용 기록은 앱 내 선택만 | 단순, 개인정보 범위 최소 | 노트 제목 폴더 스캔 |
| 목록형 화면 | 왜 걸렸는지 보이고 태그 보정에 유리 | 격자형 |
| 한/영 태그 + 초성 + 한영 보정 | 실제 입력 습관 반영 | 오타 허용 부분 일치 |
| Windows 표시 범위만, 피부색 제외 | 제목에 넣었을 때 깨짐 방지, 목록 간결 | 최신 유니코드 전체 |
| PC별 개인 데이터, Git 배포 | 공개 저장소에 개인 데이터가 섞이지 않음 | 폴더 경로 지정, Git 공유 |
| `small-win-tools` 묶음 레포 | 소형 Windows 유틸 관리 일원화 | 독립 레포 |

## 10. 가정 (사용자가 위임한 판단)
- UI는 PySide6로 한다. tkinter는 Windows에서 컬러 이모지와 한글 조합 중 갱신 처리가 불안정하기 때문.
- 피부색 변형은 1차 버전에서 제외한다.
- 최대 Emoji 버전 기본값 15.0. 회사/집 PC에서 깨져 보이는 항목이 있으면 낮춘다.
- 시작 프로그램 등록은 README에 `shell:startup` 바로 가기 방법만 안내한다(자동 등록 기능 없음).
- 레지스트리의 현재 `DisabledHotkeys` 값은 `V`라고 가정한다.

## 11. 미결 사항
- **DisabledHotkeys로 Win+.이 실제로 꺼지는지 미검증.** 이 값은 Explorer가 등록하는 단축키에만 적용되는데, 이모지 패널은 입력기(TextInputHost) 쪽에서 처리할 가능성이 있다. 안 꺼지면 5번 표의 규칙대로 보조 단축키를 쓰고, 다른 차단 방법은 별도로 검토한다.
- Win+;(세미콜론)도 이모지 패널을 연다. 같이 끌지 여부 (끄려면 `º`, VK 0xBA 추가).
- 회사 PC의 보안 프로그램이 `SendInput` 또는 전역 단축키를 막는지 여부.
